# Decisões visuais

- Mobile first com barra de abas fixa na região inferior e respeito a safe areas.
- Desktop mantém navegação horizontal compacta e conteúdo máximo de 1240 px.
- Estados críticos combinam cor, borda, texto e ícone.
- Valores financeiros usam números tabulares e maior peso visual.
- Efeitos são curtos e removidos quando o sistema solicita movimento reduzido.
- Em modo leve são removidos textura, blur e sombras pesadas.
- Todos os IDs, data attributes e mensagens existentes foram preservados.
